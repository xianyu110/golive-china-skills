# 生成式 AI 服务备案 / 算法备案要点 · GenAI Filing & Algorithm Filing

> 属于 [golive-china-skills](https://github.com/xianyu110/golive-china-skills)。核对日期：2026-10-04。**这是监管最活跃、变化最快的领域；本文不是法律意见，务必向属地网信办确认。**

**English summary:** Decide which track your AI product is on: (a) **model filing (备案)** if you provide your own generative model service to the public with public-opinion attributes or social-mobilisation capacity; (b) **registration (登记)** with the local CAC if your app/feature calls an already-filed model via API; (c) **algorithm filing** on beian.cac.gov.cn for qualifying recommendation/deep-synthesis services. Then display model name + filing/launch number, add explicit & implicit AI-content labels (mandatory since 2025-09-01), and check the anthropomorphic-interaction rules (since 2026-07-15) for companion-style bots.

## 规则速览（均已核对官方原文）

| 规则 | 要点 | 来源 |
|---|---|---|
| 《生成式人工智能服务管理暂行办法》（2023-08-15 施行） | 第十七条：提供**具有舆论属性或者社会动员能力**的生成式 AI 服务，应开展安全评估，并按《算法推荐管理规定》履行算法备案和变更、注销备案手续 | [^genai] |
| 网信办备案公告（2026-01-09） | 对**通过 API 或其他方式直接调用已备案模型能力**的生成式 AI 应用或功能，由**地方网信办开展登记**；已上线应用应在显著位置或产品详情页**公示所使用已备案或登记生成式 AI 服务情况，注明模型名称、备案号或上线编号** | [^gg2026] |
| 《互联网信息服务算法推荐管理规定》 | 具有舆论属性或社会动员能力的算法推荐服务提供者，应在提供服务之日起 **10 个工作日内**通过算法备案系统填报；变更 10 个工作日内、终止 20 个工作日内办理 | [^algo][^algo-sys] |
| 《人工智能生成合成内容标识办法》（2025-09-01 施行）+ 强制性国标 | 显式标识（用户可感知的文字/声音/图形）+ 隐式标识（文件元数据，含内容属性、服务提供者名称或编码、内容编号）；提供下载/复制/导出时文件中应含显式标识；在用户服务协议中说明标识方法与样式 | [^label][^label-qa] |
| 《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行） | 向境内公众提供模拟自然人人格特征的**持续性情感互动服务**（陪伴、情感支持等）适用；智能客服、知识问答、工作助手等不涉及持续性情感互动的不适用；提供者应履行算法备案，网信部门年度核验 | [^anthro] |

已备案/登记名单：网信办定期发布公告（例如截至 2026-08-31 的公告），用来查询你要调用的模型是否已备案。[^gg-latest]

## 判断树（agent 执行，结论交给 human 与网信办确认）

1. 产品是否**面向中国境内公众**提供？（仅内部员工使用、或纯 B2B 不面向公众的，口径不同 → 标记"需咨询"）
2. 是否**具有舆论属性或者社会动员能力**？（例如：用户可公开发布/传播生成内容、社区、对话面向公众开放等 → 倾向"是"。⚠️ 认定由监管部门把握，本 skill 只给倾向）
3. 你是**自研/自部署模型对外提供生成服务**，还是**调用他人已备案模型的 API**？
   - 自研/微调后对外 → 大模型**备案**路径（材料多、周期长）
   - 仅调用已备案模型 → 属地网信办**登记**路径
   - 调用**未备案模型或境外模型**对境内公众提供服务 → ⚠️ 高风险，见 `llm-api-in-china`
4. 是否属于**拟人化情感陪伴**？→ 额外适用 2026 年拟人化互动办法
5. 无论哪条路径：**AI 内容标识**都要做。

## 步骤

1. **产品画像（agent）**：读代码与 PRD，输出：AI 功能列表、调用的模型与供应商、是否公开传播、是否陪伴类、用户输入是否留存/用于训练。
2. **路径判定（agent → human 确认）**：按判断树给出"备案 / 登记 / 算法备案 / 暂不需要（需确认）"。
3. **联系属地网信办（human）**：获取当地最新材料清单与表格（登记通常涉及：申请表、调用模型证明、用户协议、隐私政策、内容安全管理制度、拦截关键词库、测试题、测试账号等——⚠️ 以上为业内经验汇总，**以属地网信办发放的清单为准**）。
4. **内容安全工程（agent）**：输入/输出双向审核（关键词 + 模型审核）、投诉举报入口、日志留存、违规处置流程、拒答策略；把这些写成"内容安全管理制度"草稿。
5. **标识工程（agent）**：
   - 显式：对话界面"内容由 AI 生成"提示；图片角标；音视频开头/结尾提示；导出文件中保留显式标识；
   - 隐式：在图片/音视频/文件元数据写入 AI 生成属性、服务提供者名称或编码、内容编号（按强制性国标的字段要求实现）。
6. **公示（agent）**：在产品详情页或显著位置写明"本服务使用 {{模型名称}}（备案号：{{…}}）/ 上线编号：{{…}}"。[^gg2026]
7. **算法备案（human，如适用）**：https://beian.cac.gov.cn 填报，准备算法自评估报告与拟公示内容。[^algo-sys]
8. **小程序/App 审核配合**：提审时附上备案/登记信息说明（见 `wechat-miniprogram-launch`、`app-store-ruanzhu`）。

## 检查清单

- [ ] 已判定路径并由属地网信办/律师确认
- [ ] 所调用模型在网信办已备案名单中可查
- [ ] 产品页公示模型名称 + 备案号 / 上线编号
- [ ] 显式标识：界面提示 + 导出文件中保留
- [ ] 隐式标识：元数据字段符合国标
- [ ] 用户协议写明标识方法与样式、禁止删除标识
- [ ] 输入输出内容审核、投诉举报、日志留存
- [ ] 用户输入是否用于训练——如是，隐私政策告知并取得同意
- [ ] 陪伴/情感类产品对照拟人化互动办法逐条自查

## 常见问题与修复

| 问题 | 修复 |
|---|---|
| 小程序/App 审核要求提供 AI 资质 | 提供登记/备案信息或所调用模型的备案号说明 |
| 调用的模型未备案或为境外模型 | 换用已备案国产模型（`llm-api-in-china`） |
| 生成图片导出后无标识 | 在导出流程加显式水印 + 元数据隐式标识 |
| 无内容审核/投诉入口 | 补齐审核链路与举报入口 |

## Agent 能做 vs 人必须做

| Agent | 人 |
|---|---|
| 产品画像、路径倾向判断、材料清单草稿 | 与属地网信办沟通、确认路径、提交材料 |
| 实现内容审核、标识、公示、日志 | 签署承诺、承担主体责任 |
| 起草内容安全管理制度、测试题集初稿 | 律师审阅、配合安全评估与抽检 |
